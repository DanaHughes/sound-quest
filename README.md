# Sound Quest

Interactive science-of-reading sound/spelling practice built from Dana Hughes's
Phonics Sound Cards and homeschool phonics lesson plan.

- **Sound Quest** (`index.html`): the student version. One path of sound "stops"
  with stars, no grade levels.
- **Phonics Sound Studio** (`parent.html`): the parent/teacher version, with the
  lesson-plan guide, timers, and the full scope and sequence.

Every lesson follows the same five steps: meet the card (chant and movement),
read it, write it, spell it (dictation), and word hunt. Card pictures and the
recorded chants and sounds are Dana Hughes's own.

The site is built from the `phonics-app` folder of the Science-of-Reading project
with `build-site.sh`; edit there and rebuild rather than editing these files by hand.
